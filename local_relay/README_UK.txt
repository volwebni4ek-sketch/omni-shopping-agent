====================================================================
  OMNI SHOPPING AGENT — Локальний збір з домашнього IP (3 кроки)
====================================================================

Навіщо це потрібно?
Деякі сайти (OLX, Prom, AliExpress, Amazon DE) блокують хмарні IP,
але чудово відкриваються з вашого домашнього інтернету (Київстар /
Воля / Укртелеком / мобільний роутер). Цей скрипт не потребує
встановлення жодних бібліотек — працює на стандартному Python 3.

КРОК 1. Підготовка (один раз)
  - Переконайтеся, що на ноутбуці встановлено Python 3
    (Windows: Microsoft Store -> "Python 3.12" або python.org).
  - Скопіюйте всю папку `local_relay` (або відкрийте її з Google Drive).

КРОК 2. Запуск (1 клік)
  - На Windows: двічі клікніть `START_LOCAL_HARVEST.bat`.
  - На Mac / Linux: відкрийте термінал у цій папці та виконайте:
      python3 omni_residential_harvester.py --tasks relay_tasks.json

  (За бажанням: додайте прапор `--chrome`, якщо на ноутбуці є Chrome/Edge
   і ви хочете щоб OLX рендерився через локальний браузер.)

КРОК 3. Передача результатів у Antigravity
  Після завершення в папці `output/` з'являться два файли:
  1) `COPY_TO_ANTIGRAVITY.md` — автоматично відкриється у Блокноті.
     Натисніть Ctrl+A -> Ctrl+C і просто вставте в чат Antigravity!
  2) `latest_relay_result.json` — повний JSON-файл для команди
     `omni-agent ingest-relay local_relay/output/latest_relay_result.json`
     (можна також передати в чат або зберегти в Google Drive).

Примітка з безпеки:
  Скрипт ніколи не обходить CAPTCHA чи Cloudflare. Якщо сайт показує
  перевірку "Я не робот", скрипт просто зберігає пряме посилання
  для ручної перевірки та йде далі.
